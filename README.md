# Weather App

A Flutter mobile application that provides weather information using a weather API.

The application retrieves weather data from an external API and presents it through an interactive and user-friendly interface.

## Role

Flutter Developer

Independently designed and developed the application.

## Technologies

- Flutter
- Dart
- REST APIs
- Dio
- Lottie
- Provider
- Geolocator
- Intl

## Features

- Real-time weather data
- API integration
- Location-based weather information
- Weather animations
- Temperature and weather details
- Date and time formatting

## Project Type

Mobile Application
